# Gallery — Villa-Metal

Arquivos da nova seção Gallery, organizada por Temporada 2025 e Temporada 2026.

- `gallery.html`: página principal dos álbuns.
- `gallery/photos/*.html`: uma página própria para cada foto, com metatags Open Graph para thumb grande no WhatsApp.
- `gallery/assets/*.jpg`: imagens JPEG usadas pelo WhatsApp nas prévias.
- `gallery/assets/*.webp`: imagens otimizadas para carregamento da galeria.
- `index.html`, `lineup.html` e `studio-report.html`: menu atualizado com o item Gallery.

As fotos não traziam data e local confirmados nos arquivos originais. Por isso, esses campos aparecem como “data a confirmar” e “local a confirmar”, sem inventar informações.
